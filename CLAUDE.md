# Jazz Scat - AI Jam Partner

## Achievement
**2nd Place** - ElevenLabs Worldwide Hackathon (Singapore, Dec 11, 2025)

## Timeline
- **Dec 11, 2025**: Hackathon demo version - core functionality shipped for competition
- **Dec 12, 2025+**: Post-hackathon polish - shipping improvements due to user traction and LinkedIn engagement

## Tech Stack
- Next.js 16 + React 19 + TypeScript
- ElevenLabs Conversational AI + Sound Generation
- Tailwind CSS 4 + Radix UI
- Web Audio API for mixing

## Key Commands
```bash
npm run dev         # Start dev server
npm run build       # Production build
npm run lint        # ESLint
npm run test:agent  # Test ElevenLabs connection
```
